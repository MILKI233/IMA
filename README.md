# מערכת אמא במשמרת — משימות + קמפיין המכירה הסינית

זהו עותק של מערכת ניהול המשימות (מבוסס על "מערכת הגמ"ח") שהותאם לארגון **אמא במשמרת**, עם **מודול קמפיין המכירה הסינית** חדש משולב בתוכה.

כתובת: **http://localhost:3900** · הפעלה: לחיצה כפולה על `start-ama.vbs`, או `node server.js`.

## מה יש כאן
- **מודול משימות** — `/` (דף הבית, תפריט צד לפי הרשאות)
- **קמפיין המכירה הסינית** — `/campaign.html`, לשונית "קמפיין המכירה הסינית" בתפריט. מחובר לשלוחת ימות המשיח בקו **077-556-0486**.
- **ניהול הרשאות לפי דרגה** — לשונית "ניהול והרשאות" (למנהלת/אהובי בלבד). כל אזור, כולל הקמפיין, ניתן להפעלה/כיבוי לכל דרגה בנפרד — שינוי נשמר מיד ונאכף גם בשרת, לא רק מוסתר בתפריט.
- **מודול מלאי והשכרה** (`/inventory.html`) — **כבוי כברירת מחדל**, לא רלוונטי לארגון הזה. אפשר להפעיל בלשונית חיבורים אם בכל זאת יידרש.
- כניסת מנהלת ראשונית: קוד **1111**.

## קמפיין המכירה הסינית — מה בנוי
- **שלוחה 2** (נקודות): דיווח פנייה לעסק / שליחות / גיוס מוצר (ממתין לאישור הנהלה)
- **שלוחה 3** (יעד שבועי): קביעה, אישור עמידה ביעד, בונוס אחוזי
- **שלוחה 4** (מוקדי הפצה): ניווט אמיתי לפי אזור→עיר→שכונה (29 יעדים, מהרשימה שנמסרה), + אזור ניהול מוקד מוגן PIN
- **שלוחה 7** (מימוש מתנה): לפי קוד מוצר, בנקודות
- לשונית "מיתוג והגדרות" בתוך הקמפיין: לוגו + צבעים + נקודות לכל פעולה + אחוז המרה — הכל ניתן לשינוי בלי תכנות
- שלוחות 1/5/6/9 (שיתופים/תמיכה/תוכן/הודעות צוות) — עדיין לא נבנו, מוצגות כ"יתווסף בקרוב"

## חשוב — לפני שמחברים את הקו בפועל
1. **שלוחה "3" בקו 0775560486 כבר תפוסה בפועל** (חדר ועידה/שידור חי עם הקלטות אמיתיות). יש לבחור מספר שלוחה פנוי אחר (למשל שלוחה דו-ספרתית) ולעדכן את `/yemot-campaign` בהתאם ב-`ext.ini`, או לתאם עם מי שמנהל את שאר הקו.
2. **המערכת עדיין רצה מקומית בלבד.** לחיבור אמיתי לימות המשיח צריך כתובת ציבורית קבועה 24/7 (לא מחשב אישי + טאנל זמני) — זו החלטת פריסה שצריך לקבל לפני האירוע.

## מה הועתק ממערכת הגמ"ח ומה שונה
הקוד הבסיסי (משימות, הרשאות, ניהול משתמשות, מלאי) **הועתק כפי שהוא** מ-`D:\Users\User\Downloads\GemachTasks` — התוכנה המקורית שם **לא נגעה בה ולא שונתה**. השינויים בעותק הזה:
- נוסף מודול הקמפיין (`server/campaign-api.js`, `server/campaign-yemot.js`, `public/campaign.html/js/css`)
- נוסף feature `campaign` לטבלת ההרשאות
- כבויה זריעת 105 תבניות המשימות הספציפיות לגמ"ח השמלות (לא רלוונטיות לארגון הזה) — ניתן להגדיר תבניות משימות חדשות בלשונית ניהול
- שם מסד הנתונים שונה ל-`ama-tasks.db` (לא משותף עם מסד הגמ"ח)
- הפורט שונה ל-3900

## נתונים
`data` נשמר ב-`ama-tasks.db` באותה תיקייה (או ב-`%APPDATA%` אם מותקן כ-Electron). גיבוי אוטומטי כלול במנגנון הקיים.
